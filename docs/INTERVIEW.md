# Principal Engineer interview discussion

Be ready to discuss:

1. Why MCP standardizes tool connectivity but does not replace authorization.
2. Stateless gateway scaling and why state belongs in external stores.
3. Tool schema/version governance across hundreds of teams.
4. Tenant isolation and confused-deputy prevention.
5. OAuth audience/resource indicators.
6. Human approval as deterministic policy, not model judgment.
7. Idempotency and ambiguous outcomes for write tools.
8. Rate limits at tenant, principal, agent and tool dimensions.
9. Audit data vs secret/PII minimization.
10. Failure isolation, circuit breakers and downstream health routing.
11. Tool poisoning / prompt injection from tool metadata and outputs.
12. How to evaluate an MCP gateway: auth bypass rate, policy bypass rate, latency overhead, availability, schema compatibility and cost.
